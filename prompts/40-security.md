## Copy

**Browser title:** Security and premises — Feld Company

**Meta description:** Where work runs, what may leave the building, how a model is disqualified, and how a write-binding is signed. A spec in prose.

**Eyebrow:** The firm · Premises

**Headline:** The file stays in a place you can point to.

**Dek:** Security for this firm is a set of premises questions, answered before a binding goes live. We write them down because "enterprise grade" is not an answer a keeper can use.

### Premises

The system of record remains where the company already put it. The agent runs in a tenant the company's administrator can see and revoke. Cartography notes that the company considers sensitive stay in their premises. We do not take a copy home to make the demo nicer.

### What may leave

A draft that the loop card allows to leave, after release, to the party the process already sends it to. Nothing else leaves because a model vendor's default is generous. If a model retains prompts or documents for its own training, it is disqualified for that process. Disqualification is a line in the weather log and a line in the access design. Idris signs both.

### Write access

Read-only needs a review. Write access needs a named signature from premises, after shadow week, scoped to the fields the redraw names. Write access does not widen because a Friday would be smoother. A revoked key takes effect on the company's side, and we practice the revocation once, on purpose, during the install.

### Attestation

Draft, edit, and release are stored where the company keeps its other records of the process, for as long as those records are kept, and no longer as a special hoard. The floor can see the attestation of a file they touched. A hidden log is not attestation. It is surveillance, and we will not build it on the people who do the work.

### People

Pods use the customer's identity system when they are in the building. Access expires. A badge that outlives the season of leaving is a defect. Personal inboxes are not a binding and not a place to pass a file "just this once."

### This website

The letter you send from Begin is the only thing this marketing site asks to hold. It is read by a person. Measurement is off unless you accept it. There is no chat widget listening in the corner. The colophon is the short version of this paragraph.

### Close

If your security team wants the spec in their template, we will answer in their template. The content will be these paragraphs, with your system names in them.
